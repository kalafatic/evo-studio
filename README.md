# EVO-Studio

### EVO STUDIO — AI Coding Platform

EVO-Studio is an independent, extensible AI coding platform designed to coordinate and integrate multiple coding agents, development tools, LLM providers, and software engineering workflows.

Its primary purpose is to provide a unified development environment in which users can delegate, monitor, review, and manage complex software development tasks.

**EVO-Studio is a standalone product.** It must operate independently of EVO, TRYST, and any other external application.
